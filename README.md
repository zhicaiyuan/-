# 年魂

2D 横版动作 RPG（Unity）。在森林与城堡之间探索、战斗、收集材料，通过技能树与工艺台强化角色，挑战多阶段 Boss。

## 环境要求

| 项目 | 版本 |
|------|------|
| Unity | **2022.3.62f3c1**（与 `ProjectSettings/ProjectVersion.txt` 一致） |
| 平台 | Windows（主要开发与游玩环境） |
| IDE | Visual Studio / Rider（可选） |

主要依赖（已由 Package Manager 管理）：

- Unity 2D Feature
- Cinemachine `2.10.5`
- TextMeshPro
- uGUI

## 快速开始

1. 用 Unity Hub 打开本仓库根目录（含 `Assets`、`ProjectSettings`、`Packages` 的文件夹）。
2. 等待首次导入完成。
3. 打开场景：`Assets/Scenes/主菜单.unity`
4. 点击 Play 进入主菜单；也可直接打开任意关卡场景进行调试。

> 建议从主菜单「新游戏 / 继续」进入，以便正确初始化存档与跨场景的 `AudioManager` 等管理器。

## 游戏内容概览

- **探索**：森林区域（苏醒之地、落叶小径、深根等）与城堡区域（骑士前厅、图书馆、钟楼、决战之巅等）
- **战斗**：普通敌人、战斗房间波次、Boss 战（含多阶段机制，如时之王）
- **成长**：灵魂货币、技能树解锁、装备与词条、材料收集与工艺台打造
- **系统**：存档读档、检查点祈祷、背包 / 储藏、BGM / SFX、过场视频

## 开发说明

- 脚本语言：C#
- 玩家与多数敌人采用**状态机**组织行为
- `AudioManager`、部分管理器为跨场景常驻（DontDestroyOnLoad）
- 战斗房通关进度、技能解锁、背包等会写入本地存档
- 新游戏会清理战斗房等进度相关存档，避免旧数据残留

## 常见问题

**没有背景音乐 / 战斗音乐？**  
请从主菜单进入游戏。主菜单场景中的音频管理器会跨场景保留；直接从中间关卡 Play 时，若场景未放置完整音频管理器，可能出现无 BGM。

**技能树上悬停没有说明？**  
技能描述在技能槽的 `skilldescription` 字段中配置；悬停使用全局属性提示框显示。

**Unity 版本不一致导致报错？**  
请改用本仓库记录的 `2022.3.62f3c1`，或自行评估升级后的 API / 包兼容性。
